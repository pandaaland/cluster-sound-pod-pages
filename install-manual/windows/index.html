Installation Guide

cluster Sound Album
Windows版インストール手順書

対象：Windows
全10ステップ

ダウンロードしたセットアップファイルを実行し、アプリのインストールと初回起動時の利用規約への同意を行います。

ご確認ください： 必ず正規の配布元からダウンロードしたセットアップファイルを使用してください。
1

セットアップファイルを開く

ダウンロードした cluster-sound-album-（バージョン）-win32-x64-setup-unsigned.exe をダブルクリックします。

2

警告の詳細を表示する

「WindowsによってPCが保護されました」と表示されたら、配布元を確認して「詳細情報」をクリックします。

cluster Sound Album1 / 5

Security Permission

セットアップを実行する

Windows SmartScreen

3

「実行」を選ぶ

アプリ名を確認し、正規の配布元から入手したファイルであることを確認して「実行」をクリックします。

4

セットアップを開始する

セットアップ画面が表示されたら、内容を確認して「次へ」をクリックします。

cluster Sound Album2 / 5

Installation

アプリをインストールする

セットアップ

5

インストール先を確認する

通常は表示されたインストール先を変更せず、「インストール」をクリックします。

6

インストールの完了を待つ

進行状況が表示されます。完了画面に切り替わるまで、そのまま待ちます。

cluster Sound Album3 / 5

First Launch

インストールを完了して起動する

初回起動

7

セットアップを完了する

「cluster Sound Albumを実行」のチェックを入れたまま、「完了」をクリックします。

8

使用許諾契約書を確認する

初回起動時に表示されるソフトウェア使用許諾契約書を最後まで確認します。

cluster Sound Album4 / 5

Completed

利用を開始する

セットアップ完了

あと少しで準備完了です

使用許諾契約書へ同意すると、cluster Sound Albumのメイン画面が開きます。

9

使用許諾契約書に同意する

内容に同意できる場合はチェックボックスを選択し、「同意して開始」をクリックします。

10

アプリの画面を確認する

「Sound Album」のメイン画面が表示されたら、インストールは完了です。
