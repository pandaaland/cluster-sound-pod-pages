Installation Guide

cluster Sound Album
macOS版インストール手順書

対象：macOS
全7ステップ

ダウンロードしたディスクイメージからアプリをインストールし、初回起動時のセキュリティ許可を行います。

ご確認ください： セキュリティ設定の変更時に、Macの管理者パスワードまたは管理者のTouch IDが必要です。
1

アプリをApplicationsへコピーする

ダウンロードしたディスクイメージ（DMG）を開き、cluster-sound-album.app を「Applications」フォルダへドラッグします。

2

アプリを起動する

「アプリケーション」フォルダを開き、コピーした cluster-sound-album.app をダブルクリックします。

cluster Sound Album1 / 4

Security Permission

セキュリティ警告を解除する

初回起動時のみ

3

警告を閉じる

「“cluster-sound-album.app”は開いていません」と表示されたら、「完了」をクリックします。

4

システム設定から「このまま開く」を選ぶ

「システム設定」→「プライバシーとセキュリティ」を開き、セキュリティ欄に表示されたアプリの右側にある「このまま開く」をクリックします。

cluster Sound Album2 / 4

Security Permission

アプリの実行を許可する

初回起動時のみ

5

確認画面で「このまま開く」を選ぶ

アプリを開くか確認されたら、内容を確認して「このまま開く」をクリックします。

6

管理者認証を行う

管理者のTouch IDで認証するか、「パスワードを使用…」をクリックして管理者パスワードを入力します。

cluster Sound Album3 / 4

Completed

起動を確認する

インストール完了

これでインストールは完了です

次回からは「アプリケーション」フォルダの cluster-sound-album.app をダブルクリックするだけで起動できます。

7

アプリの画面が表示されることを確認する

「Sound Album」の画面が表示されたら、正常に起動しています。
